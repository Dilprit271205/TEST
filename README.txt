IKORI static presentation deployment

1. Unzip this archive.
2. Open https://app.netlify.com/drop and drag the IKORI_Netlify_Deploy folder into the deploy area.
3. For an existing Netlify site, open its Deploys page and drag the same folder into its deploy dropzone.

The publish folder contains index.html at its root. No build command or environment variables are needed. All events, scores, actions, and notifications are simulated in the browser; this package does not contain the research backend.
